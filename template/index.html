FAQ

Preciso ter experiência com IA para aproveitar o livro?
Não. Você precisa de experiência com .NET. O livro pressupõe que você já escreve código em C# e ASP.NET — não que você entenda de machine learning ou LLMs. A parte de IA é abordada do ponto de vista prático: o que funciona, como usar, o que evitar.
Qual versão do .NET é usada nos exemplos?
Os exemplos usam .NET 8 e .NET 9. A maioria dos conceitos se aplica a qualquer versão moderna do .NET (6+). Onde há diferença relevante, isso está anotado no texto.
O conteúdo vai ficar desatualizado rápido?
Os fundamentos de como usar Claude Code bem — estrutura de contexto, fluxos de trabalho, integração com pipelines — mudam muito menos do que as versões de modelo. O livro foca nisso. Além disso, você recebe todas as atualizações futuras sem custo adicional.
Posso usar em projetos que não são .NET?
Boa parte do conteúdo — prompts, estrutura de contexto, automação, CI/CD — se aplica a qualquer stack. Os exemplos de código são em C# e ASP.NET, então se você não toca em .NET, algumas seções vão exigir adaptação. Mas os princípios são universais.
